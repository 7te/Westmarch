# Tag index

Controlled tag list. This is a vocabulary file, not a note: it has
no frontmatter, no id, and it is not indexed as a note.

Start with links only, plus status and type if needed. Add topic
tags only after retrieval actually fails, and only from this
controlled list.

There is no numeric tag limit. If a note needs many tags, consider
whether it is two notes — see Tags in the README. The human, at
review or anytime in conversation, can split, merge, or retag a
note with a prompt based on what they want.

- example-tag: replace this with your own controlled tags, one per line,
  with a short definition for each.

Original tags from imported notes are not adopted automatically - add
them here deliberately, or leave them in the original note only.
